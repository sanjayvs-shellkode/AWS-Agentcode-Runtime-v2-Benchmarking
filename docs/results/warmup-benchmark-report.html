What Does Warmup Do?

Memory Phase

Goal: Load objects into snapshot

• Pre-create boto3 client
• Import heavy modules (Strands, MCP)
• Cache endpoint resolution

Disk Phase

Goal: Prime files for fast reads

• SSL certificates
• CA bundle files
• HTTP library native code

Conclusions

Finding Details
V2 is the big win Switching from V1 to V2 reduces cold start overhead by 66% (4.5s → 1.5s)
Warmup adds modest benefit The warmup hook saves an additional ~200ms on cold starts
Basic warmup is sufficient Simple HTTPS requests in disk phase work as well as complex MCP calls
Warm requests are equal V1 and V2 perform the same on subsequent requests in a session
